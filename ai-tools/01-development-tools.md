# AI 开发工具推荐

## 代码编辑器

### Cursor
- **官网**: https://cursor.sh
- **特点**: AI-First IDE，基于 VS Code
- **功能**: Cmd+K 生成代码 / Cmd+L 对话 / Composer 多文件编辑
- **价格**: 免费版 + Pro $20/月

### Windsurf (Codeium)
- **官网**: https://codeium.com/windsurf
- **特点**: Cascade 深度上下文，AI Flow 编程
- **价格**: 免费版可用

### Zed
- **官网**: https://zed.dev
- **特点**: Rust 开发，极致性能，内置 AI 助手

## AI 代码助手

### GitHub Copilot
- **官网**: https://github.com/features/copilot
- **价格**: $10/月

### Claude (Anthropic)
- **官网**: https://claude.ai
- **特点**: 强推理能力，适合复杂任务

### ChatGPT (OpenAI)
- **官网**: https://chat.openai.com
- **特点**: GPT-4o 模型，多模态

## CLI 工具

### Warp

- **特点**: AI 终端，命令自动补全

### Fig

- **特点**: 命令行自动补全
