# AI 开发工具推荐

## 代码编辑器 & IDE

### Cursor
- **官网**：https://cursor.sh
- **定位**：AI-First 代码编辑器
- **核心功能**：
  - 基于 VS Code，无缝迁移
  - Cmd+K 快速生成/修改代码
  - Cmd+L 与 AI 对话讨论代码
  - 支持 Claude、GPT-4 等多种模型
  - Composer 功能支持多文件编辑
  - 自动理解项目上下文
- **适合场景**：日常开发、代码重构、学习新技术
- **价格**：免费版 + Pro $20/月

### GitHub Copilot
- **官网**：https://github.com/features/copilot
- **定位**：代码自动补全助手
- **核心功能**：
  - 实时代码补全
  - 根据注释生成代码
  - 支持几乎所有编程语言
  - 与 GitHub 生态深度集成
  - Copilot Chat 对话功能
  - Copilot Workspace（新）全流程开发
- **适合场景**：日常编码、减少重复代码
- **价格**：$10/月（个人）、$19/月（企业）

### Windsurf (Codeium)
- **官网**：https://codeium.com/windsurf
- **定位**：AI Flow 编程范式编辑器
- **核心功能**：
  - Cascade 深度上下文理解
  - 自动执行多步骤任务
  - 实时代码补全
  - 支持多种 LLM
- **适合场景**：复杂项目开发
- **价格**：免费版可用

### Zed
- **官网**：https://zed.dev
- **定位**：高性能协作编辑器
- **核心功能**：
  - Rust 开发，极致性能
  - 内置 AI 助手
  - 实时协作编辑
  - 极简设计
- **适合场景**：追求性能的开发者
- **价格**：免费

## AI 编程助手

### Claude (Anthropic)
- **官网**：https://claude.ai
- **定位**：最强编程对话 AI
- **核心功能**：
  - 200K token 超长上下文
  - Artifacts 实时预览代码
  - 深度代码理解和生成
  - 支持图片输入
  - Projects 功能管理长期项目
- **适合场景**：复杂问题讨论、架构设计、代码审查
