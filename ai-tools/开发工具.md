# AI 开发工具推荐

## AI 代码编辑器

### Cursor

| 项目 | 内容 |
| --- | --- |
| 官网 | https://cursor.sh |
| 定位 | AI-First IDE，基于 VS Code |
| 功能 | Cmd+K 代码生成、Cmd+L 对话、Composer 多文件编辑、Terminal 命令执行 |
| 价格 | 免费版（Pro $20/月） |
| 特点 | 集成 Claude 3.5 Sonnet，代码补全强，适合全栈开发 |

### Windsurf (Codeium)

| 项目 | 内容 |
| --- | --- |
| 官网 | https://codeium.com/windsurf |
| 定位 | AI 增强编辑器 |
| 功能 | Cascade 深度上下文、Flow 编程模式、代码补全 |
| 价格 | 免费版可用 |
| 特点 | 轻量级，对 Copilot 免费替代 |

### Zed

| 项目 | 内容 |
| --- | --- |
| 官网 | https://zed.dev |
| 定位 | 高性能代码编辑器 |
| 功能 | Rust 开发、极致性能、内置 AI 助手 |
| 价格 | 免费 |
| 特点 | 打开大型项目快如闪电 |

### Windsurf vs Cursor vs Zed

| 工具 | 适合人群 | 优势 | 劣势 |
| --- | --- | --- | --- |
| Cursor | 全栈开发者 | 功能全面、生态丰富 | 内存占用较高 |
| Windsurf | 轻量用户 | 免费、功能够用 | 生态不如 Cursor |
| Zed | 性能党 | 极快响应 | 插件较少 |

## AI 测试

### agent-qa

| 项目 | 内容 |
| --- | --- |
| 官网 | https://vostride.com |
| 定位 | Web、Android 和 iOS 自然语言测试 |
| 功能 | 测试编写、运行、失败分诊，支持 CLI、仪表板、MCP 与 Agent Skills |
| 价格 | 本地包免费，模型服务费用另计；许可证 FSL-1.1-ALv2 |
| 特点 | 持久记忆引擎复用测试经验，自我改进经验证后才保留新知识 |

需要 Node.js 24+ 及相应浏览器或设备工具。在 MCP 客户端配置下列 stdio 服务命令，具体参数见[接入文档](https://vostride.com/docs/agent-qa/mcp)：

```sh
npx agent-qa mcp
```
