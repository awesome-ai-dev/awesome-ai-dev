## 使用方式

### 在 Cursor 中引用

```markdown
@.cursor/rules/react      # 使用 React 规范
@.cursor/skills/database  # 使用数据库技能
@.cursor/agents/architect # 调用架构师代理
```

### 在提示词中引用

```markdown
@ai-tools/01-development-tools  # 查看开发工具
@prompts/04-code-generation    # 使用代码生成模板
```
