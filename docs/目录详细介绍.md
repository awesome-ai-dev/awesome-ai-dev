## 使用方式

### 在 Cursor 中引用

```text
@.cursor/rules/react      # 使用 React 规范
@.cursor/skills/database  # 使用数据库技能
@.cursor/agents/architect # 调用架构师代理
```text

### 在提示词中引用

```text
@ai-tools/开发工具   # 查看开发工具
@prompts/代码生成   # 使用代码生成模板
```text
