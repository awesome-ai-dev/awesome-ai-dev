# UI 设计与修改提示词

## 1. 页面设计

### 1.1 从零设计页面

```markdown
请为我设计一个 [页面类型] 页面：

页面用途：[描述页面的功能和目标用户]

设计风格：
- 整体风格：[现代简约/科技感/商务专业/活泼年轻/极简主义]
- 配色方案：[深色主题/浅色主题/品牌色 #XXXXXX]
- 字体风格：[无衬线/衬线/等宽]

页面内容：
1. [区块1描述]
2. [区块2描述]
3. [区块3描述]

技术要求：
- 框架：[React/Vue/Next.js]
- 样式：[Tailwind CSS/CSS Modules/styled-components]
- 组件库：[Shadcn/Radix/Headless UI]（可选）

特殊要求：
- 响应式适配（移动端优先/桌面端优先）
- 暗色模式支持
- 动画效果：[页面进入动画/hover 效果/滚动动画]
```

### 1.2 落地页 (Landing Page)

```markdown
请为我的 [产品/服务] 设计一个高转化率的落地页：

产品信息：
- 产品名称：[名称]
- 一句话描述：[核心价值主张]
- 目标用户：[用户画像]
- 核心卖点：
  1. [卖点1]
  2. [卖点2]
  3. [卖点3]

页面结构要求：
1. Hero 区域（标题、副标题、CTA 按钮、配图/视频）
2. 功能特性展示（3-4 个核心功能）
3. 用户评价/案例展示
4. 定价方案（如适用）
5. FAQ
6. 底部 CTA

设计要求：
- 使用 Next.js + Tailwind CSS
- 现代、专业的视觉风格
- 流畅的滚动动画
- 移动端完美适配
- 加载速度优先（使用 next/image）
```

### 1.3 后台 Dashboard

```markdown
请设计一个后台管理系统的 Dashboard 页面：

数据展示需求：
- 统计卡片：[今日用户数/订单数/销售额/...]
- 图表：[折线图-趋势/柱状图-对比/饼图-占比]
- 数据表格：[最近订单/待处理事项]
- 快捷操作入口

设计要求：
- 技术栈：[React + Shadcn/Vue + Element Plus]
- 布局：左侧菜单 + 顶部导航 + 内容区
- 支持暗色模式
- 卡片使用阴影和圆角
- 图表使用 [Recharts/ECharts/Chart.js]

请生成完整的组件代码，包含：
1. 布局组件
2. 统计卡片组件
3. 图表组件（使用模拟数据）
4. 数据表格组件
```

## 2. 组件设计

### 2.1 通用组件

```markdown
请设计一个 [组件名称] 组件：

功能描述：[组件的用途和功能]

Props 要求：
- variant: [primary/secondary/ghost/...]
- size: [sm/md/lg]
- disabled: boolean
- loading: boolean
- [其他 props]

交互要求：
- Hover 效果
- Focus 状态（键盘可访问）
- Loading 状态展示
- 禁用状态样式

技术要求：
- 使用 [React/Vue] + TypeScript
- 样式：Tailwind CSS
- 支持 className/class 透传
- 支持 ref 转发（React）
- 完整的类型定义

请同时生成：
1. 组件代码
2. 使用示例
3. Props 说明
```

```markdown
请设计一个完整的表单组件，包含以下字段：

2. [字段名] - [类型] - [验证规则]
3. ...

功能要求：
- 实时验证 + 提交验证
- 错误提示展示
- Loading 状态
- 成功/失败反馈

技术栈：
- [React Hook Form + Zod / VeeValidate + Zod]

请生成：
1. Zod Schema 定义
2. 完整的表单组件
3. 各个字段组件
4. 提交处理逻辑
```

## 4. 特定 UI 场景

### 4.1 空状态设计

```markdown
请为以下场景设计空状态 UI：

场景列表：
1. 数据列表为空
2. 搜索无结果
3. 网络错误
4. 无权限访问
5. 功能开发中

每个空状态需要：
- 插图/图标
- 标题文案
- 描述文案
- 操作按钮（如适用）

设计风格：[简约/插画/图标]
技术栈：[React/Vue] + Tailwind CSS
```

### 4.2 加载状态设计

```markdown
请为我的应用设计一套加载状态 UI：

需要的加载状态：
1. 全局页面加载
2. 组件级 Loading
3. 按钮 Loading
4. 骨架屏（列表/卡片/详情页）
5. 进度条（上传/下载）

设计要求：
- 统一的视觉风格
- 流畅的动画
- 可复用的组件

技术栈：
- [React/Vue]
- Tailwind CSS + CSS 动画
```

### 4.3 错误提示设计

```markdown
请为我的应用设计一套错误提示 UI：

场景类型：
1. 表单验证错误（字段级）
2. 操作失败 Toast
3. 全局错误页面（500/404/403）
4. 网络错误提示
5. 业务异常提示（如余额不足）

设计要求：
- 清晰的错误说明
- 提供解决建议
- 合适的颜色和图标
- 可关闭/自动消失

技术栈：
- [React/Vue]
- Tailwind CSS
- Toast 库：[sonner/react-hot-toast]
```

## 5. 设计系统

请帮我建立一套设计规范/Design System：

品牌信息：
- 品牌名称：[名称]
- 品牌调性：[专业/活泼/科技/...]
- 主品牌色：[#XXXXXX]

需要定义的规范：
1. 颜色系统（主色、中性色、语义色）
2. 字体系统（字族、字号、行高）
3. 间距系统（4px 基准）
4. 圆角规范
5. 阴影规范
6. 动画规范

输出格式：
- Tailwind 配置文件
- CSS 变量定义
- 使用说明文档
```

6. Modal / Dialog

技术要求：
- [React/Vue] + TypeScript
- Tailwind CSS
- 完整的 Props 类型定义
- 键盘可访问性
- 支持暗色模式

请为每个组件提供：
1. 组件代码
2. 类型定义
3. 使用示例
```
