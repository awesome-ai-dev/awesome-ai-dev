# Bug 修复提示词

## 调试流程

```
1. 定位问题 → 2. 分析原因 → 3. 修复 → 4. 验证
```

## 提示词模板

```markdown
请帮我分析并修复这个 Bug：

## 问题描述
[描述问题现象]

## 复现步骤
1. 打开页面
2. 点击按钮
3. 出现错误：[错误信息]

## 期望行为
[描述期望的正确行为]

## 相关代码
\`\`\`
[粘贴相关代码]
\`\`\`

## 环境信息
- 框架版本：
- 浏览器：
```

## 常见问题模式

### 异步问题
- 未等待异步完成
- 回调地狱
- Promise 未处理

### 状态问题
- 状态更新不及时
- 闭包陷阱
- 引用类型共享

### 类型问题
- null/undefined 未处理
- 类型断言过度
- 泛型推断失败

## 调试技巧

```typescript
// 添加日志
console.log('state:', state);

// 使用断点
debugger;

// 检查类型
console.log(typeof value);
```
