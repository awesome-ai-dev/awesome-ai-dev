# 测试工程提示词

## 单元测试

```markdown
请帮我编写单元测试：

## 目标
- 测试文件：xxx
- 框架：Vitest / Jest

## 要求
1. 覆盖主要逻辑
2. Mock 外部依赖
3. 断言清晰
```

## E2E 测试

```markdown
请帮我编写 E2E 测试：

## 场景
- 用户登录流程
- 表单提交

## 工具
- Playwright / Cypress

## 要求
1. 模拟真实用户行为
2. 断言页面状态
3. 失败截图
```

## 集成测试

```markdown
请帮我编写集成测试：

## 目标
- API 接口测试
- 数据库交互

## 方案
1. 测试数据库
2. 清理测试数据
```
