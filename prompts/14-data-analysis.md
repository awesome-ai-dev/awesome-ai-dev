# 数据分析提示词

## 数据处理

```markdown
请帮我进行数据分析：

## 数据
- 来源：xxx
- 字段：xxx

## 分析目标
1. 描述性统计
2. 趋势分析
3. 异常检测
```

## 可视化

```markdown
请帮我生成数据可视化：

## 图表类型
- 折线图/柱状图/饼图

## 工具
- Matplotlib / Seaborn / ECharts

## 要求
1. 图表美观
2. 数据清晰
```

## 报表生成

```markdown
请帮我生成数据分析报告：

## 内容
1. 数据概览
2. 关键指标
3. 趋势分析
4. 建议
```
