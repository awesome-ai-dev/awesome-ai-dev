# DevOps 提示词

## CI/CD 配置

```markdown
请帮我配置 CI/CD：

## 平台
- GitHub Actions / GitLab CI

## 流程
1. 代码检查
2. 测试
3. 构建
4. 部署

## 环境
- 开发 / 预发布 / 生产
```

## Docker 配置

```markdown
请帮我配置 Docker：

## 应用
- 框架：xxx
- 依赖：xxx

## 要求
1. 多阶段构建
2. 镜像优化
3. 健康检查
```

## 监控告警

```markdown
请帮我配置监控：

## 指标
- CPU / 内存
- 请求延迟
- 错误率

## 工具
- Prometheus / Grafana
- Sentry

## 告警规则
- 阈值设置
- 通知渠道
```
