# 前端开发提示词

## React 19 开发

```markdown
请帮我用 React 19 实现功能：

## 需求
- 功能：xxx
- 组件：xxx

## 技术
- React 19
- TypeScript
- Server Actions
- use() hook

## 要求
1. 使用函数组件和 Hooks
2. 默认使用 Server Components
3. 客户端用 'use client' 标记
4. 类型完整，无 any
```

## Vue 3 开发

```markdown
请帮我用 Vue 3 实现功能：

## 需求
- 功能：xxx

## 技术
- Vue 3 Composition API
- TypeScript
- Pinia 状态管理

## 要求
1. 使用 <script setup> 语法
2. 类型完整
3. 响应式使用 ref/reactive
```

## Next.js 15 开发

```markdown
请帮我用 Next.js 15 App Router 实现功能：

## 需求
- 页面/组件：xxx

## 技术
- Next.js 15 App Router
- TypeScript
- Tailwind CSS

## 要求
1. Server Components 优先
2. 客户端用 'use client'
3. API 用 Route Handlers
4. 样式用 Tailwind dark: 前缀
```

## 组件设计

```markdown
请帮我设计组件：

## 场景
- 列表展示/表单编辑/弹窗等

## 要求
1. Props 类型完整
2. 单一职责
3. 可复用性强
4. 考虑无障碍访问
```

## 状态管理

```markdown
请帮我设计状态管理方案：

## 场景
- 全局状态/服务器状态/表单状态

## 方案选择
- 全局状态：Zustand / Redux Toolkit
- 服务器状态：TanStack Query
- 表单状态：React Hook Form + Zod
```
