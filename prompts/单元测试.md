## AI Auxiliary Testing Strategy

### 核心原则

```markdown
让 AI 生成测试的最佳实践：

1. 先写代码，再让 AI 生成测试（而不是让 AI 同时写代码和测试）
2. 提供完整的上下文（依赖、类型、业务逻辑）
3. 明确测试覆盖要求（正常情况、边界情况、异常情况）
4. 审查 AI 生成的测试，确保测试有意义
```markdown

### 测试生成流程

```markdown
1. 提供待测代码 → 2. 说明测试范围 → 3. AI 生成测试 → 4. 审查补充 → 5. 运行验证
```markdown

### 通用测试生成提示词

```markdown
请为以下代码生成完整的单元测试：

代码：
```[语言]
[粘贴待测代码]
```markdown

测试框架：[Jest/Vitest/pytest]

测试范围：

- [ ] 正常输入情况
- [ ] 边界值情况
- [ ] 异常/错误情况
- [ ] 空值/null/undefined 情况

测试覆盖率目标：[80%/90%/100%]

请确保：

1. 每个测试用例有清晰的描述
2. 使用 AAA 模式（Arrange-Act-Assert）
3. Mock 外部依赖
4. 测试相互独立

```markdown

```typescript
@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.get<string[]>('roles', context.getHandler());
    if (!requiredRoles) return true;
    
    const request = context.switchToHttp().getRequest();
    const user = request.user;
    return requiredRoles.some((role) => user.roles?.includes(role));
  }
}
```markdown

2. 用户有所需角色时应该允许访问
3. 用户没有所需角色时应该拒绝访问
4. 用户没有 roles 属性时应该拒绝访问

```typescript
export function useDebounce<T>(value: T, delay: number = 500): T {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}
```markdown

3. 快速连续变化只保留最后一个值
4. 自定义 delay 参数

```typescript
// use-debounce.test.ts
import { describe, it, expect, vi, beforeEach, afterEach } from 'vitest';
import { renderHook, act } from '@testing-library/react';
import { useDebounce } from './use-debounce';

describe('useDebounce', () => {
  beforeEach(() => {
    vi.useFakeTimers();
  });

  afterEach(() => {
    vi.useRealTimers();
  });

  it('应该立即返回初始值', () => {
    const { result } = renderHook(() => useDebounce('initial', 500));

    expect(result.current).toBe('initial');
  });

  it('应该在延迟后更新值', () => {
    const { result, rerender } = renderHook(
      ({ value, delay }) => useDebounce(value, delay),
      { initialProps: { value: 'initial', delay: 500 } }
    );

    // 更新值
    rerender({ value: 'updated', delay: 500 });

    // 延迟前应该还是旧值
    expect(result.current).toBe('initial');

    // 快进时间
    act(() => {
      vi.advanceTimersByTime(500);
    });

    // 延迟后应该是新值
    expect(result.current).toBe('updated');
  });

  it('快速连续变化只保留最后一个值', () => {
    const { result, rerender } = renderHook(
      ({ value }) => useDebounce(value, 500),
      { initialProps: { value: 'first' } }
    );

    // 快速连续更新
    rerender({ value: 'second' });
    act(() => vi.advanceTimersByTime(100));
    
    rerender({ value: 'third' });
    act(() => vi.advanceTimersByTime(100));
    
    rerender({ value: 'final' });

    // 完成延迟
    act(() => vi.advanceTimersByTime(500));

    // 应该只保留最后一个值
    expect(result.current).toBe('final');
  });

  it('应该支持自定义 delay', () => {
    const { result, rerender } = renderHook(
      ({ value, delay }) => useDebounce(value, delay),
      { initialProps: { value: 'initial', delay: 1000 } }
    );

    rerender({ value: 'updated', delay: 1000 });

    // 500ms 后还是旧值
    act(() => vi.advanceTimersByTime(500));
    expect(result.current).toBe('initial');

    // 1000ms 后是新值
    act(() => vi.advanceTimersByTime(500));
    expect(result.current).toBe('updated');
  });
});
