# 安全与认证提示词

## 认证系统

```text
请帮我设计认证系统：

## 需求
- 用户注册/登录
- 密码重置

## 技术
- JWT / Session
- OAuth2 / SSO

## 要求
1. 密码加密存储
2. Token 过期策略
3. 刷新令牌机制
```

## 权限控制

```text
请帮我设计权限系统：

## 需求
- 角色管理
- 资源权限

## 方案
- RBAC / ABAC
- 菜单权限
- 按钮权限
```

## 安全防护

```text
请帮我检查安全漏洞：

## 场景
- 用户输入处理
- API 安全

## OWASP Top 10
- SQL 注入
- XSS 攻击
- CSRF
```
