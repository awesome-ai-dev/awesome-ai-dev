# 性能优化提示词

## 前端优化

```markdown
请帮我优化前端性能：

## 目标
- 首屏加载 < 2s
- LCP < 2.5s
- FID < 100ms

## 方案
1. 代码分割
2. 图片优化
3. CDN 加速
4. 懒加载
```

## 后端优化

```markdown
请帮我优化后端性能：

## 场景
- API 响应慢
- 数据库查询慢

## 方案
1. 缓存策略
2. 数据库索引
3. 连接池
4. 异步处理
```

## 数据库优化

```markdown
请帮我优化数据库：

## 问题
- 查询慢
- 连接数高

## 方案
1. 索引优化
2. 查询优化
3. 分库分表
```
